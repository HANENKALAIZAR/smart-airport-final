# Legacy / Archived Data Files

These files are **not used by any production code path**.
They are kept for historical reference only.

## Files in this folder

| File | Origin | Status |
|---|---|---|
| `flights_dataset.csv` | Mock data generated by `generate_mock_data.py` (~5,000 synthetic rows) | **ARCHIVED — never used in production training** |
| `generate_mock_data.py` | Script that generated the mock CSV | **ARCHIVED** |
| `seed_database.py` | Old MySQL seed script that loaded mock CSV into a legacy `flights` table | **ARCHIVED — that table no longer exists** |
| `seed_data.sql` | SQL dump of the mock dataset | **ARCHIVED** |

## Production Training Source

The active ML model is trained exclusively from the **`ae_flight_dataset`**
PostgreSQL table, populated in real-time by the Aviation Edge API ingestion
pipeline (`app/services/ae_ingestion_service.py`).

Training is orchestrated by:
- **`app/ai/train_v2.py`** — multi-model pipeline (XGBoost / LightGBM / CatBoost / RF)
- Called automatically every 6 hours by `app/scheduler.py` → `_job_auto_retrain()`
- Gated by `app/ai/mlops_controller.py` → `check_retraining_policy()`

**Do not move any of these files back to `/data/` or reference them from any
active training, ingestion, or inference script.**
